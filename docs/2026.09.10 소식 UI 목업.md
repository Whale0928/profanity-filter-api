# 소식과 관리자 UI 목업

사용자 요청에 따라 UI를 먼저 검토할 수 있도록 구성했다. DB 확장과 관리자 지정은 보류했다.

## 화면

- 소식 목록: `/news`. 작은 제목, 유형별 탭, 제목 검색, 날짜와 짧은 설명으로 구성한다.
- 소식 상세: `/news?post=portal-update`. 상단 배너 없이 목록 복귀, 유형, 제목과 본문을 보여 준다. 제목은 데스크톱 25px, 모바일 23px이며 본문은 13px다.
- 관리자 목업: `/admin?preview=admin`. 소식 목록, 게시됨·임시 저장 필터, 수정·삭제, Markdown 작성·미리보기·나란히 보기와 임시 저장·게시를 제공한다.
- 로컬 개발 화면의 목업 바에서 방문자·일반 회원·관리자를 선택할 수 있다. 관리자 선택은 UI 시연이며 실제 인증이나 권한 부여가 아니다. 이 전환기는 Vite 개발 모드에서만 표시된다.
- 실제 로그인과 관리자 표시값을 모두 만족하는 경우 관리자 메뉴를 표시하는 UI 조건을 갖췄다. 실제 권한 계약과 서버 측 검증은 후속 백엔드 단계에서 확정해야 한다.

## 데이터와 경계

로컬 소식은 예시 데이터 5개와 임시 저장 예시 1개로 시작한다. 편집과 삭제는 브라우저 메모리에만 반영되며 새로고침하면 초기화된다. 실제 게시글 생성·수정·삭제 API를 호출하지 않는다. 목록의 점검 일정과 이슈는 실제 운영 공지가 아니다. 배포용 완성 기능으로 검증한 상태가 아니다.

앞서 작성한 백엔드·마이그레이션 초안은 `2026.09.10 소식 백엔드 초안.patch`에 보관하고 실행 소스에서는 분리했다. `git apply --check`로 패치 형식만 확인했다. 이 패치는 미검증 초안이며 자동 적용 대상이 아니다. 특히 UI 목업에 추가된 임시 저장 상태 등은 후속 스키마 설계에서 다시 논의해야 한다. 운영 DB 변경과 관리자 지정은 수행하지 않았다.

## 검증

- `npm --prefix ui/app run build`: TypeScript 및 Vite 빌드 통과. 기존 Scalar 번들 크기 경고는 남아 있다.
- `npm --prefix ui/app run verify:discovery`: 산출물 5개 검증 통과.
- `git diff --check`: 통과.
- Orca 브라우저에서 소식 목록·상세, 관리자 목록·편집 화면을 확인했다.
- 방문자와 일반 회원에게 관리자 메뉴가 없고, 관리자에게 메뉴가 표시됨을 확인했다. 일반 회원의 관리자 주소 직접 접근은 안내 화면으로 제한된다.
- 수정 내용의 Markdown 실시간 미리보기, 임시 저장, 게시 후 공개 목록 반영을 확인했다. 취소 확인 대화상자는 native dialog를 사용한다.
- 단독 파이프, HTML 태그, 실행용 링크를 입력했다. 파서가 멈추지 않았고, script 요소와 javascript 링크가 생성되지 않았다. 내부 문서 링크는 정상 표시됐다.
- 관리자 목록은 320·390·768·1024·1469px에서 가로 넘침 0, 소식 상세는 320·390·768·1469px에서 가로 넘침 0이었다. 모바일 목록과 390px 편집 화면도 확인했다.
- 최종 브라우저 콘솔 19개 메시지 중 오류 0개, 경고 0개였다.

UI와 문서만 변경했다. 백엔드 테스트, DB 마이그레이션, 실제 관리자 인증·권한 부여, 운영 연동은 이번 UI 단계에서 실행하지 않았다. 커밋과 배포도 수행하지 않았다.

## 관리자 디자인 최종 조정

기존 사이트의 공통 헤더와 푸터, 서체, 녹색 계열 색상을 유지한다. Cheese Lake는 ERP 정보 구조만 참고한다.

- 사이드바는 소식 관리, 필터 사전, 문의, 사용자 관리, API Key 관리의 다섯 메뉴로 구성했다. 임시 저장은 소식 내부 필터로만 제공한다.
- 문의에서는 단어 요청과 일반 문의를 구분하고 상세 확인 및 답변 저장을 시연한다. 답변은 실제로 전송되지 않는다.
- 필터 사전의 표현 추가·수정·사용 상태 변경, 사용자 계정 상태 변경, 예시 API Key 만료를 메모리에서 시연한다. 메뉴를 이동해도 상태는 유지되며 새로고침하면 초기화된다. 실제 사용자 권한이나 키를 변경하지 않는다.
- sidebar 176px, 메뉴 12px, 페이지 제목 15px, 소식 제목 13px로 정리했다. 소식 표 행 높이는 데스크톱 실측 47px다.
- 중복 제목과 카드 테두리를 제거하고 소식 제목과 배지를 한 줄로 배치했다. 접기 버튼은 사이드바 상단에 배치하고 경계선은 본문 높이를 따라가게 했다.
- 모바일은 아이콘 메뉴와 제목·상태 중심의 목록을 제공하며 제목을 누르면 상세 내용을 확인할 수 있다.

### Opus 검토

Orca orchestration의 `task_71b5abd2d784` / `ctx_c570a3801a11`에서 Claude Opus high가 초기 캡처와 코드를 읽기 전용으로 검토했다. 주요 지적은 제목 중복, 약 72px의 행 높이, 사이드바 경계 끊김, 중첩 여백과 과한 상태 칩이었다. 이 항목들을 반영했다. 최종 화면의 브라우저 검증은 코디네이터가 수행했으며 Opus가 최종 수정본을 재승인한 것은 아니다.
