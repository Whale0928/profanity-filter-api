# Overview

한국어와 영어 비속어를 검출하고, 필요하면 검출 단어를 `*`로 마스킹하는 API입니다.

### 시작하기

1. 개발자 포털에서 Google 또는 GitHub SSO로 로그인하고 API Key를 발급합니다.
2. 보호된 API는 `x-api-key` 헤더를 포함해 호출합니다.
3. `POST /api/v1/filter`에 `text`와 `mode`를 전달합니다.

API Key 원문은 발급·재발행 직후 한 번만 표시되며 분실한 키는 복구하지 않고 재발행합니다.

### 처리 모드

| Mode     | 설명                      |
|----------|-------------------------|
| `QUICK`  | 첫 번째 감지 단어를 빠르게 확인합니다.  |
| `NORMAL` | 감지된 단어 목록을 반환합니다.       |
| `FILTER` | 감지된 단어를 마스킹한 문장을 반환합니다. |

### 응답 기준

대부분의 실패는 HTTP 상태 코드가 아니라 응답 본문의 `status.code`로 구분합니다.
`callbackUrl`을 전달하면 요청은 접수 응답을 먼저 반환하고, 이후 같은 `trackingId` 기준으로 비동기 결과 전달을 시도합니다.

### 허용 단어 그룹

서비스마다 허용할 단어가 다르면 개발자 포털에서 허용 단어 그룹을 만들고, 필터 요청의 `whitelistIds`에 그룹 ID를 넣습니다. 그룹에 든 단어는 그 요청의 검출과 마스킹에서 빠집니다.

- 한 번에 5개까지 넣을 수 있고, 여러 그룹을 넣으면 허용 단어를 합쳐서 적용합니다.
- `whitelistIds`를 넣지 않은 요청은 기존과 같습니다.
- 계정에 연결된 API Key로만 쓸 수 있습니다. 그룹을 찾지 못하면 `4090`, 상한을 넘으면 `4091`, 계정에 연결되지 않은 키이면 `4092`로 응답합니다.
- 그룹을 고치면 1분 안에 반영됩니다.
