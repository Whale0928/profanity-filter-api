욕설 필터링이 필요한 곳

채팅, 댓글, 닉네임의 비속어 필터링을 API 호출 한 번으로 처리합니다.

  • 게임·커뮤니티 채팅 욕설 차단

    메시지를 보내기 전에 QUICK 모드로 욕설 포함 여부만 빠르게 확인합니다.

  • 댓글·게시글 비속어 마스킹

    FILTER 모드는 검출한 비속어를 *로 가린 문장을 돌려줘 그대로 저장하거나 노출할 수 있습니다.

  • 닉네임·프로필 금칙어 검사

    NORMAL 모드로 검출된 단어와 위치를 모두 받아 가입 단계에서 안내합니다.

  • 서비스에 맞춘 허용 단어

    계정별 허용 단어 그룹으로 사전에 있어도 걸러내지 않을 단어를 직접 정합니다.

Aho-Corasick 기반 다중 패턴 매칭으로 사전 단어 수와 무관하게 문장 길이에 비례한 시간에 응답합니다. 띄어쓰기와 특수문자로 변형한 표기도 정리해 비교합니다.
